# Changes

## 0.11 — rooms, time zones and a fix for some emulators

- **Office directory** is a full screen with department and phone. It was a pop-up window, which some 5250 emulators drew on top of the menu without clearing it.
- **Documents** are a compact list, fourteen to a page, instead of cards.
- **Group chat rooms** with topics, newest topic first. F6 makes a room, F9 changes the topic.
- **Settings**: time zone, week starts on Sunday or Monday, working day hours, and 12-hour or metric (24-hour, day.month.year) units.
- Appointments can be typed in any time zone and are stored in office time. The day screen shows the time now in the office and in your zone.
- The settings file is now OVSETUP. If you built 0.10, the old OVSETP file is no longer used and can be deleted.

## 0.10 — settings

- Main menu option 9 is now **Settings**: animations on or off, the calendar character, the screen saver delay and chat refresh, as well as name, phone and pop-ups.
- The calendar menu no longer redraws every second, which made the cursor jump back to the first field. The character holds still and only moves in a screen saver after a few idle minutes.
- Live chat only redraws when a new line arrives.
- New file OVSETP holds each person's settings.

## 0.9 — the OfficeVision calendar

- The calendar now opens on a **Process Calendars** menu, with day, N-day, business-week, boxed month and six-month views, printing, conference rooms, meetings with clash checking, shared calendars, holidays and calendar search.
- The main menu is shorter, with submenus for mail and chat, the organizer, documents, and games.
- The build reports screen files that are in use, instead of failing with no reason given.
- Fixes for the reminder service, the calendar screen file and Tetris.

## 0.8
